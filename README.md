# 機械鍵盤規格與社群評價分析

本專題旨在透過 Python 爬蟲技術，自動蒐集原價屋線上估價頁的鍵盤品名與價格資料，以及巴哈姆特電玩資訊站周邊討論板的論壇標題。透過 pandas 進行資料清理與整合，分析不同規格（如軸體、配列）與售價之間的關係，同時探討各品牌在社群中的討論傾向。本專題為 4 週學習計畫，涵蓋資料蒐集、資料處理、資料庫儲存與視覺化呈現等完整流程。

## 資料來源

- 原價屋線上估價頁（鍵盤品名與價格）
- 巴哈姆特電玩資訊站周邊討論板（論壇標題）

## 環境安裝

```bash
pip install -r requirements.txt
```

## 使用說明

依 Week1 到 Week4 資料夾中的腳本依序執行
